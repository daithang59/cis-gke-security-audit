# Lab C: Service Account & Workload Identity

Mục tiêu lab:
- Triển khai kịch bản kiểm thử bảo mật GKE liên quan đến Google Service Account (GSA) và Kubernetes Service Account (KSA).
- Thử nghiệm cấu hình Workload Identity hợp lệ vs cấu hình vi phạm (e.g., Default compute engine service account, IAM over-permission).
